# Lead qualification

Turn a candidate row into a usable Hub piste. Work from the public evidence and
the owner’s objective, not from assumptions about the community.

## Workflow

1. Check the destination URL, source URL, platform, type, and language.
2. Merge an existing row when the canonical URL or catalog key matches.
3. Set one objective: tester, organizer, photographer, or partner.
4. Set the visible stage: `À qualifier`, `À suivre`, `À contacter`, `Contacté`,
   `Réponse`, `Actif`, or `Écarté`.
5. Keep relation and contact status separate. A page can be followed without
   being contacted; a message can be prepared without being sent.
6. Write one next action that a human can complete and one short qualification
   note explaining the choice.

## Completion evidence

The Hub row has a non-empty objective, a stage, a next action or an explicit
reason for `Écarté`, and no duplicate external URL. If evidence is missing,
keep the row at `À qualifier` and say what must be checked.

Never follow, join, message, scrape members, or publish while qualifying.
