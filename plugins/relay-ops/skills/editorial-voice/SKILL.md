# Editorial voice

Write in the owner's voice only from an approved voice profile, prior examples,
or answers provided in the current task.

## Before writing

- Load the voice profile from Relay when it exists.
- If it does not exist, ask for a small set of examples or state that the voice
  is not yet captured.
- Separate voice preferences from factual product rules.
- Preserve the owner's meaning, uncertainty, and boundaries.

Do not infer private opinions from the product, imitate a person from a name, or
claim that a draft sounds like the owner without evidence.

## Drafting rules

For a publication, produce one recommended draft and flag any factual claim that
needs confirmation. For a reply, use this order when it fits:

1. acknowledge the person;
2. answer the concrete point;
3. offer the next useful step.

Match the requested channel and relationship. Do not over-explain, promise an
unreleased feature, argue with a negative comment, or turn a short reaction into
a sales pitch.

## Output

Return:

```text
Channel:
Purpose:
Draft:
Voice choices:
Facts to confirm:
Approval: needs review
```

Never publish, reply, or send a message from this skill. It only produces copy
for the publication workflow.
